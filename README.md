# 우리의 작은 우주 ♥ — 커플 앱

Uniple의 공개 페이지에 소개된 기능 구성을 참고해 새로 만든 개인용 PWA입니다. 원본 코드나 브랜드 자산을 복제하지 않습니다.

## 포함 기능
- 만난 날 D-day 및 다음 기념일 표시
- 커플 일기, 일정, 기념일
- 버킷리스트 체크
- 운동 기록
- 영화/드라마/게임/음악 기록
- 사진 앨범(사진 URL 방식)
- 데이트 가계부 합계
- 장소 기록 및 지도 열기
- 비밀 메모
- JSON 백업/복원
- PWA 홈 화면 설치
- Supabase Broadcast 기반 실시간 상태 공유(설정 필요)

## 먼저 알아둘 점
기본 상태에서는 브라우저의 localStorage에 저장되며, 이 기기에서만 보입니다. `supabase-config.json`에 Supabase URL과 anon key를 설정해야 실시간 공유 연결을 시도합니다. 이 초기 버전은 빠른 개인용 프로토타입입니다. 실시간 공유를 프로덕션에서 안전하게 쓰려면 Supabase Auth와 비공개 채널/DB 정책을 추가해야 합니다. `anon key`는 브라우저에 노출되는 키이므로 service_role 키를 절대 넣지 마세요. 현재의 Broadcast 설정은 링크/프로젝트 정보를 아는 사람이 접근할 수 있는 구성일 수 있으므로 민감한 일기나 비밀 메모를 넣기 전 보안 설정을 강화하세요.

## 아이패드 초보자용 배포 방법: GitHub Pages
1. GitHub.com에서 계정을 만들거나 로그인합니다.
2. 새 저장소(repository)를 만듭니다. 예: `our-couple-app`. 공개 저장소로 만들면 앱 소스가 공개되므로, 소스 공개가 싫다면 비공개 호스팅을 선택하세요.
3. 이 ZIP을 풀고 파일들을 저장소 최상위에 업로드합니다.
4. `Settings → Pages`로 들어갑니다.
5. `Deploy from a branch`를 선택하고 `main` / `/(root)`를 고른 뒤 Save를 누릅니다.
6. 몇 분 후 표시되는 Pages 주소를 Safari에서 엽니다.
7. iPad Safari의 공유 버튼 → `홈 화면에 추가`를 누릅니다.

## 실시간 공유 구성
1. https://supabase.com 에서 프로젝트를 생성합니다.
2. 프로젝트의 `Project URL`과 `anon/public key`를 복사합니다.
3. `supabase-config.json`의 `url`과 `anonKey`에 값을 넣고 다시 배포합니다.
4. 두 사람 모두 같은 배포 URL을 열고 새로고침합니다.

### 보안 관련 중요 안내
이 ZIP의 공유 기능은 초기 테스트용 Broadcast 방식입니다. 로그인/초대 코드/행별 접근 정책을 구현하지 않은 상태이므로 진짜 비밀 공간처럼 안전하다고 간주하면 안 됩니다. 실사용 전에는 Supabase Auth, 공유 커플 ID, RLS가 적용된 데이터 테이블, Storage 버킷 정책을 추가해야 합니다. 민감한 정보는 테스트 버전에 저장하지 마세요. 사진 앨범은 이 버전에서는 사진 파일 업로드가 아니라 이미지 URL을 기록합니다.
